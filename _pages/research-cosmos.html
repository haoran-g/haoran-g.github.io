COSMOS
COSMOS: RL-Enhanced Locality-Aware Counter Cache Optimization for Secure Memory
Published in: 58th IEEE/ACM International Symposium on Microarchitecture (MICRO), 2025
Authors: Haoran Geng, Xiaoyang Lu, Yuezhi Che, Ziang Tian, Dazhao Cheng, Xian-He Sun, Michael Niemier, X. Sharon Hu
Background

Secure memory systems using AES-CTR encryption face a critical performance challenge: each cache miss triggers additional DRAM accesses to fetch the encryption counter (CTR), leading to severe overhead — especially in workloads with irregular memory access patterns like graph algorithms, where CTR cache miss rates can reach 90%. Existing solutions such as MorphCtr improve CTR density, but even at a 1:128 CTR-to-data ratio, irregular workloads still suffer high miss rates because counters are only accessed after LLC misses, behaving effectively as an inefficient "L4" cache.

Design

COSMOS integrates two reinforcement learning (RL)-based predictors into the memory controller. The RL-based data location predictor determines whether requested data resides on-chip or off-chip after an L1 miss, enabling speculative CTR fetching for predicted off-chip accesses — removing cache-hierarchy latency from the critical path. The RL-based CTR locality predictor classifies CTRs as high- or low-locality, feeding a locality-centric replacement cache (LCR-CTR) that retains hot CTRs longer. Both predictors use tabular Q-learning with hardware-efficient lookup tables, adding only 147 KB of on-chip storage.

RL prediction accuracy

COSMOS achieves 25% performance improvement over MorphCtr and 10% over EMCC for irregular memory workloads, while maintaining near-zero overhead on regular workloads. The data location predictor achieves ~85% accuracy across graph benchmarks, outperforming traditional pattern-based prefetchers that achieve less than 60% precision on irregular workloads.

Conclusion

COSMOS demonstrates that reinforcement learning can effectively address the irregular-access CTR cache problem without complex modifications to the cache hierarchy. By enabling earlier CTR access and smarter replacement decisions, COSMOS brings secure memory performance significantly closer to non-protected baselines.
